# TEMPER

TEMPER is a research program investigating whether expensive general-purpose reasoning can be progressively compiled into cheap, calibrated, verifiable decision primitives.

## Research Question

Can specialized probabilistic decision models, combined with calibrated abstention, independent verification, and selective escalation, reduce cost per verified correct decision relative to direct general-purpose generative inference?
